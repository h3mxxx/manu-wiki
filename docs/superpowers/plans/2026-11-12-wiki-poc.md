# Wiki POC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 提供可验证的 XWiki POC、可复现部署和后续 AI/Office 接入方案。
**Architecture:** 官方 XWiki LTS + PostgreSQL Compose；单独命名卷；复用模型与 Office 服务需有实际端点。
**Tech Stack:** XWiki17.10.15、PostgreSQL16.15、Docker Compose、官方扩展。
**Spec:** docs/superpowers/specs/2026-11-12-wiki-poc-design.md

## Global Constraints

- 不采购、不删现有数据、不修改生产、不全量迁移。
- 不重复部署模型；密钥不入库、不进报告。
- 问题按阻塞/一般/优化分级，非关键失败不反复重装。

## Review Focus

- 重跑初始化不能覆盖密码；用临时目录运行两次检查摘要一致。
- 缺失配置应拒绝启动；使用 compose config -q 验证。
- 数据库不公开、XWiki默认回环地址；检查实际映射。
- 内容和附件跨容器重建仍在；用示例页面验证。
- 草稿及模型数据不能越权；多角色验收，无端点时明确未验证。
