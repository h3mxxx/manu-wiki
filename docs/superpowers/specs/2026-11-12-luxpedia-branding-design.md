# LuxPedia 品牌配置

用户选择 LuxPedia，要求替换用户界面的 XWiki Logo、说明和相关链接。采用白色字标、蓝色主题，定位为“企业知识库”。仓库名称暂不改变。

## 方案

采用官方主题、站点偏好、面板及菜单配置，建立独立 LuxPedia 主题和本地帮助/关于页面。相比复制核心模板或用全局 JavaScript 搜索替换文字，此方案修改范围小、易升级回退。具体实现由执行者选择，用户已确认品牌名称及替换目标。

替换页头 Logo、图标、浏览器标题、站点显示名称、页脚和首页说明；普通用户导航移除上游宣传/帮助入口，提供站内帮助。后台类名、API/URL、上游源文件、许可证和技术文档中的组件名称保留真实信息。关于页面记录第三方组件和许可证。

只操作当前隔离 POC。配置及自建页面写入仓库，可重复应用，变更前保存本地受保护快照。不删除现有知识，不修改权限体系或已发布 v0.1.0 标签。验证登录前后、桌面及窄屏展示，运行既有只读冒烟测试，按现有发布流程提交后续变更。
